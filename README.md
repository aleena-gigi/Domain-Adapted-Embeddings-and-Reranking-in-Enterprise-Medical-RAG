# Domain-Adapted Embeddings and Reranking in Enterprise Medical RAG

AAI-590 capstone project (University of San Diego, MS in Applied Artificial Intelligence).
Domain-adapts the retrieval stack of a clinical-note RAG system by fine-tuning a bi-encoder
(BAAI/bge-m3) and a cross-encoder reranker (BAAI/bge-reranker-v2-m3) on the MedEmbed clinical
triplet dataset, and measures whether the resulting retrieval gains also improve the
faithfulness of generated answers, with the generation model held frozen throughout.

Team: Aleena Gigi, Sunil Prasath, Neha Pandey.

## Repository layout

| Path | Project element | Description |
|---|---|---|
| `notebooks/01_eda.ipynb` | Exploratory Data Analysis | Downloads the [MedEmbed training triplet dataset](https://huggingface.co/datasets/abhinand/MedEmbed-training-triplets-v1) from Hugging Face and computes the statistics and figures used in the report's Data Summary section: query/passage length distributions, anaphoric-query rate, negative-passage reuse frequency, degenerate-positive rate, query-type breakdown, and query-positive lexical overlap. Each analysis step is documented in markdown cells explaining the rationale and takeaway. Read-only — does not filter, clean, or split the dataset. |
| `figures/fig1_length_distributions.png` | EDA output | Query and passage length histograms. |
| `figures/fig2_negative_reuse.png` | EDA output | Distribution of how many distinct queries each negative passage is reused by. |
| `figures/fig3_query_type.png` | EDA output | Keyword-style vs. natural-question-style query breakdown. |
| `figures/fig4_lexical_overlap.png` | EDA output | Jaccard word overlap between each query and its positive passage. |

Data cleaning (anaphoric-query filtering, false-negative removal, degenerate-positive removal,
train/val/test corpus split), model design and training (bi-encoder fine-tuning, negative
mining, reranker fine-tuning), model optimization (hyperparameter sweeps), and model/pipeline
analysis (evaluation harness, faithfulness harness, results) are not yet implemented and will
be added to this repository as separate, clearly labeled files as the project progresses.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install datasets pandas matplotlib numpy huggingface_hub jupyter nbformat
```

## Running the EDA

```bash
cd notebooks
jupyter nbconvert --to notebook --execute --inplace 01_eda.ipynb
```

Or open `01_eda.ipynb` directly in Jupyter/VS Code and run all cells. Prints summary statistics
inline alongside each analysis step and writes all four figures to `../figures/`.

## Dataset

[MedEmbed-training-triplets-v1](https://huggingface.co/datasets/abhinand/MedEmbed-training-triplets-v1)
(Apache 2.0), built from PubMed Central clinical notes. 21,689 unique queries, 27,590 unique
corpus passages, 232,684 total triplet rows. Query, positive-passage, and negative-passage
labels were generated by prompting LLaMA 3.1 70B over the source text.
